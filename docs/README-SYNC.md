# همگام‌سازی گوشی و ویندوز

داده‌ها روی **سرور خودت** می‌مانند و جای دیگری نمی‌رود. سمت اپ از قبل داخل
`www/index.html` پیاده شده است — فایل جداگانه‌ای لازم نیست.

نصب سمت سرور، نشانی‌ها، پشتیبان‌گیری و رفع اشکال: **[`server/README.md`](../server/README.md)**

خیلی کوتاه:

```bash
cd ~/sobhan-server && sudo ./install.sh sync
sudo nano /opt/sobhan/sync.env        # APP_TOKEN را بگذار
sudo systemctl restart sobhan-sync
curl -s localhost:8788/sync/health
```

بعد در اپ ← تنظیمات ← کارت «همگام‌سازی گوشی و ویندوز»: آدرس
`http://آی‌پی‌سرور:8788` و همان رمز را وارد کن، «همگام‌سازی خودکار» را تیک بزن و
«همگام‌سازی الان» را بزن. بار اول از دستگاهی شروع کن که داده دارد.

## چطور کار می‌کند

- رکورد به رکورد ادغام می‌شود، نه فایل کامل: تغییر هم‌زمان روی دو دستگاه،
  هر دو می‌ماند.
- اگر همان رکورد روی هر دو عوض شود، تغییر جدیدتر می‌ماند.
- حذف هم منتقل می‌شود و رکورد حذف‌شده دوباره زنده نمی‌شود.
- همگام‌سازی: هنگام باز شدن برنامه، هر ۱۰ دقیقه، و با دکمه‌ی دستی.
- داده‌ی سرور در `/opt/sobhan/sync-data.json` با یک کپی روزانه‌ی `.bak`.

## محدودیت فعلی

عکس‌های خرابی (که در IndexedDB ذخیره می‌شوند) هنوز همگام نمی‌شوند؛ بقیه‌ی
داده‌ها بله.
