# همگام‌سازی گوشی و ویندوز از طریق سرور خودت

داده‌ها روی **سرور خودت** می‌مانند؛ جای دیگری نمی‌رود. هر دو نسخه همین یک
فایل `sync.js` را اجرا می‌کنند، پس مثل بقیه قابلیت‌ها فقط یک‌بار نوشته می‌شود.

## ۱) روی سرور
```bash
sudo cp sync-server.js /opt/sobhan-ai/
sudo cp sobhan-sync.service /etc/systemd/system/
sudo nano /etc/systemd/system/sobhan-sync.service   # APP_TOKEN را بگذار
sudo systemctl daemon-reload
sudo systemctl enable --now sobhan-sync
curl http://127.0.0.1:8788/sync/health
```
پورت ۸۷۸۸ را در فایروال باز کن: `sudo ufw allow 8788/tcp`

با Caddy (پیشنهادی، چون رمز رمزنگاری می‌شود):
```
ai.yourdomain.com {
    reverse_proxy /sync/* 127.0.0.1:8788
    reverse_proxy 127.0.0.1:8787
}
```

اگر سرور خارجی از ایران مستقیم در دسترس نیست، همان پل ایرانی را برای پورت
۸۷۸۸ هم فوروارد کن.

## ۲) در مخزن اپ
۱. فایل `sync.js` را در پوشه‌ی `www` بگذار.
۲. در `www/index.html` این خط را **به‌عنوان اولین اسکریپت** داخل `<head>` اضافه کن:
```html
<script src="sync.js"></script>
```
۳. commit و push. هر دو ساخت (APK و ویندوز) خودکار به‌روز می‌شوند.

## ۳) در هر دو نسخه
دکمه‌ی گرد «⟳ همگام» پایین-چپ صفحه می‌آید. بزن و وارد کن:
- آدرس: `https://ai.yourdomain.com` یا `http://آی‌پی‌سرور:8788`
- رمز: همان `APP_TOKEN`
- «فعال باشد» و «همگام‌سازی خودکار» را تیک بزن

**بار اول:** اول روی **گوشی** (که داده دارد) «ارسال کامل این دستگاه» را بزن،
بعد روی ویندوز فقط «ذخیره و همگام‌سازی». از آن به بعد خودکار است.

## چطور کار می‌کند
- رکورد به رکورد ادغام می‌شود، نه فایل کامل: اگر روی گوشی ساعت‌کارکرد میکسر را
  عوض کنی و هم‌زمان روی ویندوز یک ماشین جدید اضافه کنی، هر دو می‌مانند.
- اگر **همان رکورد** روی هر دو دستگاه عوض شود، تغییر جدیدتر می‌ماند.
- حذف هم منتقل می‌شود (رکورد حذف‌شده روی دستگاه دیگر هم پاک می‌شود).
- همگام‌سازی: هنگام باز شدن برنامه، هر ۲ دقیقه، و چند ثانیه بعد از هر تغییر.
- اگر داده‌ی جدیدی از دستگاه دیگر برسد، صفحه یک‌بار تازه می‌شود تا جدول‌ها به‌روز شوند.
- داده‌ها روی سرور در `/opt/sobhan-ai/sync-data.json` است و روزانه یک کپی
  `.bak` کنارش ساخته می‌شود.

## محدودیت فعلی
عکس‌های خرابی (که در IndexedDB ذخیره می‌شوند) هنوز همگام نمی‌شوند؛ بقیه‌ی
داده‌ها بله. اگر لازم داری، در مرحله بعد همان را هم اضافه می‌کنم.
