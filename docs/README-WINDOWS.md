# نسخه ویندوز دستیار سبحان بتن

کد رابط کاربری **مشترک** است: هر دو نسخه از همان پوشه‌ی `www` استفاده می‌کنند.
نسخه ویندوز هیچ نسخه‌ی جدایی از صفحه‌ها ندارد، پس هر قابلیتی که از این به بعد
به `www` اضافه شود، خودکار در اندروید و ویندوز هر دو ظاهر می‌شود.

## نصب فایل‌ها در مخزن
این دو مورد را کنار فایل‌های فعلی مخزن `sobhan-beton` بگذار:

```
sobhan-beton-app/
├── www/                     ← بدون تغییر (مشترک)
├── desktop/                 ← جدید
│   ├── package.json
│   ├── main.js
│   ├── preload.js
│   └── build/icon.ico, icon.png
└── .github/workflows/
    ├── build.yml            ← قبلی (اندروید)
    └── build-windows.yml    ← جدید
```

سپس:
```bash
git add -A && git commit -m "نسخه ویندوز" && git push
```

در تب **Actions** دو ساخت موازی اجرا می‌شود: `Build APK` و `Build Windows`.
حدود ۵ تا ۱۰ دقیقه بعد، از صفحه‌ی اجرای `Build Windows` فایل
`sobhan-beton-windows` را دانلود کن. داخل زیپ دو فایل است:

- `SobhanBeton Setup 1.0.0.exe` — نصب‌کننده (آیکن روی دسکتاپ می‌سازد)
- `SobhanBeton-Portable-1.0.0.exe` — نسخه بدون نصب، همین یک فایل کافی است

ویندوز بار اول ممکن است «Windows protected your PC» نشان دهد؛
روی **More info** و بعد **Run anyway** بزن (چون فایل امضای تجاری ندارد).

## نکته‌های فنی
- داده‌ها روی کامپیوتر جدا از گوشی ذخیره می‌شوند. برای یکی‌کردن، از
  همان پشتیبان‌گیری/بازگردانی یا پشتیبان روی سرور استفاده کن.
- یادآوری‌ها به‌صورت اعلان ویندوز نشان داده می‌شوند (تا وقتی برنامه باز است).
- خواندن پیامک راننده‌ها فقط روی اندروید کار می‌کند؛ روی ویندوز آن بخش
  بی‌صدا غیرفعال است و خطا نمی‌دهد.
- دستیار Claude و پشتیبان سرور روی ویندوز هم با همان آدرس و رمز سرور واسط کار می‌کند.

## قاعده‌ی توسعه از این به بعد
۱. هر قابلیت جدید فقط داخل `www` نوشته می‌شود.
۲. اگر قابلیتی به سخت‌افزار گوشی نیاز دارد، با `window.PLATFORM`
   (`"windows"` یا غیر آن) و پرچم‌های `window.HAS_SMS` / `window.HAS_CAMERA`
   شرط گذاشته می‌شود تا روی ویندوز تمیز غیرفعال شود.
۳. برای تست سریع روی کامپیوتر بدون GitHub:
   `cd desktop && npm install && xcopy /E /I ..\www www && npm start`
